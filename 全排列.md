# 全排列

## 题目解析

返回这个数组中所有元素的排列情况，不能有重复的情况

## 解题策略

总结一下这个回溯的通用模板:  
1. 全局变量“返回答案”
2. 全局变量，递归时决策树走的路径path
3. 递归出口，一般和要求长度有关
4. path因为会回溯，因此不用担心重复

回溯

```
class Solution {
    boolean[] check;  //记录元素的使用情况，不能重复
    List<List<Integer>> results;  //返回最终组合
    List<Integer> path;  //保存当前路径，方便回溯
    public List<List<Integer>> permute(int[] nums) {
        int n=nums.length;
        check=new boolean[n];
        results=new ArrayList<>();
        path=new ArrayList<>();
        //所有处理逻辑，都在递归函数中
        dfs(nums,path);
        return results;

    }

    public void dfs(int[] nums,List<Integer> path){
        //递归出口：path长度==nums长度，装满了
        if(path.size()==nums.length){
            results.add(new ArrayList<>(path));
            return;
        }
        //第一层循环
        for(int i=0;i<nums.length;i++){
            //剪枝
            if(check[i]==true){
                continue;
            }
            //加入
            path.add(nums[i]);
            check[i]=true;
            //接着向下递归
            dfs(nums,path);
            //回溯
            path.remove(path.size()-1);
            check[i]=false;
        }
    }
}
```
