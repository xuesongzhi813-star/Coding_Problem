# 相交链表与环形链表的笔记

## 环形链表

### 解题策略

设定两个快慢双指针，若链表有环，则快指针和慢指针一定会相遇

```
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        if(head==null){
            return false;
        }
        //总体策略：快慢双指针遍历，如果二者相遇则有环
        ListNode fast=head;
        ListNode slow=head;
        while(fast!=null && fast.next!=null){
            fast=fast.next.next;
            slow=slow.next;
            if(fast==slow){
                return true;
            }
        }
        return false;
    }
}
```

# 相交链表

## 解题策略

1. 分别获取两个链表的长度，相减获得两个链表长度差值

2. 较长的链表head移动“差值”，这样两个链表就在同一起跑线

3. headA，headB一起移动，两者一定会相遇，相遇就是相交节点

```
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if(headA==null || headB==null){
            return null;
        }
        //解题策略:
        //1.求出两个链表各自总长，并且求出差值
        ListNode curA=headA;
        int lengthA=0;
        while(curA!=null){
            curA=curA.next;
            lengthA++;
        }
        ListNode curB=headB;
        int lengthB=0;
        while(curB!=null){
            curB=curB.next;
            lengthB++;
        }
        int difference=lengthA>lengthB?lengthA-lengthB:lengthB-lengthA;
        //2.长的链表先移动差值距离
        if(lengthA>lengthB){
            while(difference>0){
                headA=headA.next;
                difference--;
            }
        }
        else{
            while(difference>0){
                headB=headB.next;
                difference--;
            }
        }
        //3.两个指针一起移动，一定会遇到相同的节点
        curA=headA;
        curB=headB;
        while(curA!=curB){
            curA=curA.next;
            curB=curB.next;
        }
        return curA;
    }
}
```
