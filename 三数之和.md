# 三数之和笔记

## 解题策略

双指针解题：

前提：先对数组进行一次重排序（从小到大）

1. 使用指针cur从尾部固定住区间

2. 双指针left，right在“固定的区间”内遍历，求组合

3. 重复情况应对：cur尾部固定的数可能重复，left指向的也可能重复

**一定要关注两个去重**
```class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        //先对数组进行重排序
        Arrays.sort(nums);
        List<List<Integer>> ret=new ArrayList<>();
        int left=0;
        int right=nums.length-2;
        int cur=nums.length-1;
        //循环条件：保证至少有三个数可以相加
        while(cur>=2){
            //每次循环的重置
            left=0;
            right=cur-1;
            //二层循环，遍历cur固定后，区间内的所有情况
            while(left<right){
                int sum=nums[left]+nums[right]+nums[cur];
                if(sum<0){
                    left++;
                }
                else if(sum>0){
                    right--;
                }
                else{
                    //三数之和=0，记录
                    List<Integer> list=new ArrayList<>();
                    list.add(nums[left]);
                    list.add(nums[right]);
                    list.add(nums[cur]);
                    ret.add(new ArrayList<>(list));
                    left++;
                    //去重
                    while(left<right && nums[left]==nums[left-1]){
                        left++;
                    }
                }
            }
            //去重
            cur--;
            while(cur>=2 && nums[cur]==nums[cur+1]){
                cur--;
            }
        }
        return ret;
    }
}
```
