# 翻转二叉树的笔记

## 解题原则：
从上往下遍历，每个根节点都交换，一直交换到最末端

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if(root==null){
            //递归出口：空节点返回
            return root;
        }
        //从上到下的交换
        //先交换上面的根节点的两个左右子树
        TreeNode tmp=root.left;
        root.left=root.right;
        root.right=tmp;
        //将两个左右子树的根节点调用函数，继续从上到下交换
        invertTree(root.left);
        invertTree(root.right);
        return root;
    }
}
```

#判断对称二叉树的笔记

##解题策略：
从上往下遍历这棵树的所有子树的根节点，根据对称原则：

- “左子树的左侧”与“右子树的右侧”比较

- “左子树的右侧”与“右子树的左侧”比较

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public boolean isSymmetric(TreeNode root) {
        //解题原则：左子树的左与右子树的左比较，左子树的右与右子树的左比较
        if(root==null){
            //如果是空的，就是对称的
            return true;
        }
        //重写方法，实现解题原则
        return isSymmetricR(root.left,root.right);
    }
    public boolean isSymmetricR(TreeNode left,TreeNode right){
        //这里的本质，也是从上到下实现
        //不对称情况：一边null，一边不为null
        if((left!=null && right==null) || (left==null && right!=null)){
            return false;
        }
        //当匹配成功时，返回正确
        if(left==null && right==null){
            return true;
        }
        if(left.val!=right.val){
            return false;
        }
        //从上到下实现：左的左和右的右一组，左的右和右的左一组
        return isSymmetricR(left.left,right.right) && isSymmetricR(left.right,right.left);
    }
}
```
