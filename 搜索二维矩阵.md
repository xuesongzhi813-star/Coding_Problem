# 搜索二维矩阵的笔记

## 题目解析：

本题的有两个关键条件：

1. 每一行，从左到右，一定是单调递增的

2. 本行的第一个列的数，一定是大于上一行最后一列的数

解法：

我们可以使用两次二分查找，先查找出第一列中，target最可能存在的行，再去这一行中进行第二次二分查找。找是否有target

代码的注意事项：

多提一句，一定要想清楚“目标是查找左端点，还是查找右端点”，直接套用模板，解题很快。

1. 第一次二分查找，为了查找比target小的数，但是是查找“比它小的数”中最大的那个（类似查找右端点）

2. 第二次二分查找，为了查找它本身，因此，边界条件没什么好处理的，正常二分即可

```
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int row = binarySearchFirstColumn(matrix, target);
        if (row < 0) {
            return false;
        }

        return binarySearchOrderRow(matrix, target, row);
    }

    public int binarySearchFirstColumn(int[][] matrix, int target) {
        int low = 0;
        int high = matrix.length - 1;

//** 查找右端点，因此，mid要靠右，left不能越过mid，因为不知道是否left就是最后一个比target小的数 **//
        while (low < high) {
            int mid = low + (high - low + 1) / 2;
            if (matrix[mid][0] <= target) {
                low = mid;
            } else {
                high = mid - 1;
            }
        }

        return high;
    }

    public boolean binarySearchOrderRow(int[][] matrix, int target, int row) {
        int left = 0;
        int right = matrix[row].length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (matrix[row][mid] == target) {
                return true;
            } else if (matrix[row][mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }

        return false;
    }
}
```
