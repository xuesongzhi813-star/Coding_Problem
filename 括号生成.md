# 括号生成笔记

## 问题解析

给定一个括号对数n，生成可能的所有情况，所有括号要封闭！

## 解题策略

主要是采取“回溯”，画决策树遍历所有情况，再深度优先代码实现

**细节**

1. 左括号的值始终要是>=右括号的

2. 可以采用StringBuffer直接append拼接，deleteCharAt删除。更快捷方便


```
class Solution {
    int total1;   //左括号的个数
    int total2;   //右括号的个数
    List<String> ret;
    StringBuffer path;
    public List<String> generateParenthesis(int n) {
        total1=0;
        total2=0;
        ret=new ArrayList<>();
        path=new StringBuffer();
        path.append('(');
        total1++;
        dfs(n);
        return ret;
    }
    public void dfs(int n){
        //递归出口：左右括号相等，且括号数==n，达到上限
        if(total1==total2 && total1==n){
            ret.add(path.toString());
            return;
        }

        //当左括号<n时，递归+回溯
        if(total1<n){
            path.append('(');
            total1++;
            dfs(n);

            //回溯
            path.deleteCharAt(path.length()-1);
            total1--;
        }

        //当右括号个数<左括号个数，递归+回溯
        if(total2<total1){
            path.append(')');
            total2++;
            dfs(n);

            //回溯
            path.deleteCharAt(path.length()-1);
            total2--;
        }
    }
}
```
