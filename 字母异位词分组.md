# 字母异位词分组笔记

## 题目解析

将“字母组成相同”的字符串，分到一组并且返回。其中分好的组的先后顺序不用管。

## 解题策略

采用哈希表+重排序策略：  
1. 重排序，取出String[]的元素，转化为char[]并且进行重排序，如果字母组成一样，则**结果一定一样**

2. 哈希表：key：重排序后字符串；value：List<String>，存放重排序后对应key的字符串原本的样子

```
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String,List<String>> hashMap=new HashMap<>();
        for(int i=0;i<strs.length;i++){
            //每次遍历一个串，都要进行重排序，进行key比较
            char[] sc=strs[i].toCharArray();
            Arrays.sort(sc);
            String key=new String(sc);
            //使用getOrDefault获取key对应的List
            List<String> list=hashMap.getOrDefault(key,new ArrayList<>());
            list.add(strs[i]);
            hashMap.put(key,list);
        }
        //遍历整个hash表，取出每一个key对应的list，就是答案
        List<List<String>> result=new ArrayList<>();
        for(Map.Entry<String,List<String>> entry:hashMap.entrySet()){
            result.add(entry.getValue());
        }
        return result;
    }
```
