# 排序链表笔记

## 题目解析

给定一个链表，把目标链表排序成“每个节点的值从小到大”。返回新链表的头节点

## 解题策略

排序+从小到大+链表节点（特殊数据类型）-->优先级队列

小根堆排序就是从头到尾是从小到大，因此，新链表的节点连接，按照小根堆poll的顺序即可。

```
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode sortList(ListNode head) {
        //将节点放入“优先级队列”（小根堆），自定义排序规则
        PriorityQueue<ListNode> queue=new PriorityQueue<>(
            (v1,v2)->{
                return v1.val-v2.val;
            }
        );
        ListNode cur=head;
        //将链表节点，全部放入优先级队列 
        while(cur!=null){
            queue.offer(cur);
            cur=cur.next;
        }

        ListNode newHead=new ListNode();
        newHead.next=queue.poll();
        ListNode ret=newHead;
        ret=ret.next;
        //从优先级队列中取出来的就是排序好的
         while(!queue.isEmpty()){
            ret.next=queue.poll();
            ret=ret.next;
            ret.next=null;
         }

         return newHead.next;
    }
}
```
