# 二叉树的层序遍历笔记

## 题目解析

实现二叉树的层序遍历-->每一层的元素要放在同一个数组里

## 解题策略

- 队列：先进先出，模拟上一层元素先进来，先出去（层序遍历从上到下的规则）

- 计数：每一层的遍历，先记录当前层有多少元素，防止有漏/多

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        //先判断树是否为空
        if(root==null){
            return new ArrayList<>();
        }
        List<List<Integer>> list=new ArrayList<>();
        //使用队列，来完成层序遍历-->先进先出，模拟上一层先出去
        Deque<TreeNode> queue=new ArrayDeque<>();
        //先放入第一个元素
        queue.add(root);
        while(!queue.isEmpty()){
            //先记录当前队列有多少元素-->本层有几个
            int total=queue.size();
            List<Integer> ret=new ArrayList<>();  //记录本层
            while(total>0){
                //放入total的左右孩子
                TreeNode cur=queue.poll();
                if(cur.left!=null){
                    queue.add(cur.left);
                }
                if(cur.right!=null){
                    queue.add(cur.right);
                }
                ret.add(cur.val);
                total--;
            }
            //提交本层元素
            list.add(new ArrayList<>(ret));
        }
        return list;
    }
}
```

原始笔记参考：  
解题策略:使用队列，队列先进先出的特点，可以实现从上到下，从左到右的层序遍历 
 
难点:如何记录下每一层的结果？每一层的元素是哪些（因为每次出一个，就要添加它的两个孩子进入队列）  

解决:本轮出队列之前，先记录下“当前队列中的元素个数”-->本层的元素个数，由此添加即可
