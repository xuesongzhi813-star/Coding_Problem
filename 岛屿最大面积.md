# 岛屿最大面积笔记

## 题目解析

跟“岛屿的数量”一样，只是多加入了加入队列时，要count++计数

## 解题策略

1. 遍历整个数组，去寻找“是岛屿的元素（1）”+“未被使用的元素”

2. 对这些元素进行bfs，加入队列后向四个方向扩张遍历寻找

```
class Solution {
    //上下左右方向的x，y坐标变化
    int[] dx={0,0,-1,1};
    int[] dy={1,-1,0,0};
    int m;
    int n;
    boolean[][] check=new boolean[51][51];  //足够大的检查存在数组
    public int maxAreaOfIsland(int[][] grid) {
        m=grid.length;
        n=grid[0].length;

        int maxArea=0;
        for(int i=0;i<m;i++){
            for(int j=0;j<n;j++){
                //遍历整个地图
                if(grid[i][j]==1 && !check[i][j]){
                    //是岛+未被纪录
                    int count=bfs(grid,i,j);
                    maxArea=Math.max(count,maxArea);
                }
            }
        }
        return maxArea;
    }

    public int bfs(int[][] grid,int i,int j){
        Queue<int[]> queue=new ArrayDeque<>();
        int count=0;
        queue.add(new int[]{i,j});   //记录下当前点的第一个值为x坐标，第二个值为y坐标
        check[i][j]=true;
        count++;
        while(!queue.isEmpty()){
            int[] t=queue.poll();
            int a=t[0];
            int b=t[1];
            //上下左右四个方向开始遍历
            for(int k=0;k<4;k++){
                int x=a+dx[k];
                int y=b+dy[k];
                if(x>=0 && x<m && y>=0 && y<n && grid[x][y]==1 && !check[x][y]){
                    queue.add(new int[]{x,y});
                    check[x][y]=true;
                    count++;
                }
            }
        }
        return count;
    }
}
```
