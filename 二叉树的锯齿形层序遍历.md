# 二叉树的锯齿形层序遍历

## 题目解析

本题与“层序遍历”无差异，只是增加了，本层“从左到右遍历”，下一层就要“从右到左遍历”

## 解题策略

加入队列的顺序，我们依旧不变  
但是，第二层的List采取LinkedList使用链表的头插/尾插来表示“从左到右”还是“从右到左”。  
同时，增加一个开关check判断本次采取什么方法

```
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    //队列处理层序+链表头，尾插应对“从左向右”，还是“从右向左”
    public List<List<Integer>> zigzagLevelOrder(TreeNode root) {
        boolean check=true;
        List<List<Integer>> results=new ArrayList<>();
        if(root==null){
            return new ArrayList<>();
        }
        //使用队列应对层序遍历
        Deque<TreeNode> queue=new ArrayDeque<>();
        queue.add(root);
        while(!queue.isEmpty()){
            List<Integer> ret=new LinkedList<>();
            int total=queue.size();
            while(total>0){
                TreeNode cur=queue.poll();
                if(cur.left!=null){
                    queue.add(cur.left);
                }
                if(cur.right!=null){
                    queue.add(cur.right);
                }
                //判断本轮是头插还是尾插
                if(check){
                    //尾插
                    ret.addLast(cur.val);
                    total--;
                }
                else{
                    //头插，从右向左
                    ret.addFirst(cur.val);
                    total--;
                }
            }
            results.add(new ArrayList<>(ret));
            if(check){
                check=false;
            }
            else{
                check=true;
            }
        }
        return results;
    }
}
```
